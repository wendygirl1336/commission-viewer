# 보험 수수료 조회 시스템

보험사별 수수료 엑셀 파일을 웹에서 업로드하고, 회사·상품·구분별로 빠르게 조회할 수 있도록 만든 내부 업무용 웹 애플리케이션입니다.

각 보험사마다 엑셀 양식, 병합 셀, 시트명, 상품 구분 방식, 수수료 열 구조가 달라 수작업 확인이 많았던 업무를 줄이는 데 초점을 맞췄습니다. 생명보험과 손해보험을 분리해 관리하고, 업로드된 파일의 시트별 데이터를 검색 가능한 표로 변환합니다.

## 주요 기능

- 생명보험·손해보험 업무 구분 선택
- 관리자 로그인 기반 엑셀 업로드
- 조회 계정 로그인 후 데이터 열람
- 회사명, 상품명, 구분 기준 검색 및 필터링
- 회사, 상품, 총수수료 기준 오름차순·내림차순 정렬
- 생명보험 1차년, 2차년, 3차년, 4차년, 총수수료 표시
- 손해보험 익월, 2차년도 합산금액, 총수수료 표시
- 업로드 파일의 전체 시트 자동 파싱
- 새 엑셀 업로드 시 기존 데이터에 추가 반영
- 관리자 전용 개별 수정, 삭제, 구분별 삭제, 전체 삭제
- 엑셀 퍼센트 표시값 보존

## 문제 해결 포인트

보험 수수료표는 회사마다 표 구조가 일정하지 않습니다. 이 프로젝트는 단순히 정해진 열 번호를 읽는 방식이 아니라, 엑셀 안의 실제 헤더를 기준으로 수수료 열을 찾도록 설계했습니다.

- `1차년도`, `2차년도`, `3차년도`, `4차년도`, `총수수료` 헤더 기반 추출
- 병합 셀에 숨겨진 상품명·납입기간·구분 정보 보정
- 상품명, 보종, 상품구분, 납입기간, 가입금액구간, 가입연령, 만기 등 회사별 식별 정보 결합
- `0`, `0.0%`, 엑셀 내부 소수값을 사용자에게 일관된 퍼센트 형식으로 표시
- 숨김 시트까지 포함해 전체 시트 파싱
- 생명보험과 손해보험 파서가 서로 섞이지 않도록 분리

## 사용자 흐름

1. 사용자는 첫 화면에서 생명보험 또는 손해보험을 선택합니다.
2. 로그인 후 업로드된 수수료 데이터를 조회합니다.
3. 검색창과 필터로 필요한 회사·상품을 찾습니다.
4. 표 헤더의 정렬 버튼으로 회사명, 상품명, 총수수료를 정렬합니다.
5. 관리자는 로그인 후 엑셀 업로드, 수정, 삭제 작업을 수행합니다.

## 관리자 기능

관리자는 수수료 파일을 업로드해 데이터를 갱신할 수 있습니다. 업로드된 데이터는 서버에 저장되어 다른 접속자도 같은 데이터를 조회할 수 있습니다.

- 엑셀 업로드
- 행 단위 수정
- 행 단위 삭제
- 시트 구분별 삭제
- 전체 데이터 삭제
- 업로드 진행 상태 표시

## 보안 설계

내부 업무용 도구로 사용할 수 있도록 기본적인 접근 제어와 요청 보호 기능을 적용했습니다.

- 세션 기반 로그인
- 관리자 권한과 조회 권한 분리
- 관리자 작업 CSRF 토큰 검증
- 로그인 실패 횟수 제한 및 임시 잠금
- 업로드 파일 크기 제한
- JSON 요청 본문 크기 제한
- 주요 보안 헤더 적용
- 정적 파일 경로 탐색 차단

## 기술 스택

- Python
- Python 표준 `http.server`
- openpyxl
- HTML
- CSS
- JavaScript
- Render 배포 설정

프레임워크 의존성을 최소화해 작은 서버 파일과 정적 UI만으로 구성했습니다. 배포 환경에서는 Render의 Python 웹 서비스로 실행됩니다.

## 프로젝트 구조

```text
.
├── app.py              # 서버, 인증, 엑셀 파싱, 업로드 API
├── index.html          # 조회 화면, 필터, 관리자 UI
├── requirements.txt    # Python 의존성
├── runtime.txt         # Python 런타임 버전
├── render.yaml         # Render 배포 설정
├── Procfile            # 배포 실행 명령
├── package.json        # npm start 호환 실행 스크립트
└── assets/
    └── kif-logo.png    # 서비스 로고 이미지
```

## 로컬 실행

```bash
pip install -r requirements.txt
python app.py
```

실행 후 브라우저에서 아래 주소로 접속합니다.

```text
http://127.0.0.1:8766
```

## 배포

Render 배포를 기준으로 설정되어 있습니다.

- Build Command: `pip install -r requirements.txt`
- Start Command: `python app.py`

`PORT` 환경 변수가 있으면 해당 포트를 사용하고, 없으면 로컬 기본 포트 `8766`으로 실행됩니다.

### 데이터 저장

운영 환경에서는 Postgres 연결 문자열을 `DATABASE_URL` 환경변수로 설정하면 업로드 데이터가 DB에 저장됩니다. `DATABASE_URL`이 없으면 로컬 개발용으로 `current_upload.json` 파일을 사용합니다.

```text
DATABASE_URL=postgresql://...
```

DB 연결 문자열에는 비밀번호가 포함되므로 GitHub나 문서에 직접 올리지 않고, Render의 Environment Variables에만 등록합니다.

## 작업 성과

이 프로젝트는 보험사별로 다른 엑셀 수수료표를 하나의 조회 화면으로 표준화하는 데 집중했습니다. 반복적인 엑셀 확인 업무를 줄이고, 관리자 업로드만으로 내부 사용자가 최신 수수료 정보를 검색할 수 있도록 구성했습니다.
